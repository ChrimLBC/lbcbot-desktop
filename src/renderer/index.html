    Dashboards

    Your control dashboards, each in its own window.

    Open a dashboard

    Open as many as you like — each remembers its size and position, and whichever are open when you quit come back on the next launch. You sign in once and it remembers you.

    This is also the only place the Twitch Backstage widget works properly: Twitch refuses to be embedded in a web page, so Raid Now and Start Sharing Chat — neither of which Twitch exposes an API for — are reachable here and nowhere else.

    Media playback still belongs in your normal browser: YouTube embeds serve ads in any plain Chromium, this one included. The Media Queue widget drives playback rather than hosting it.
