Add an overlay to OBS

    Creates a correctly sized browser source with a scoped overlay key. The URL is never shown or copied, so it cannot end up in a screenshot — and you can revoke it any time under Connected apps on the website.

    Dashboard

    Opens a control dashboard in its own window, so you don't need a browser for it. Open as many as you like — each remembers its size and position, and whichever are open when you quit come back on the next launch. Signs in once and remembers you.

    Media playback still belongs in your normal browser: YouTube embeds serve ads in any plain Chromium, this one included. The dashboard's Media Queue widget drives playback rather than hosting it.
